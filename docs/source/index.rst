Sociefy documentation
Welcome to Sociefy's Documentation!
===================================

Sociefy is a mobile application designed to simplify the management of university societies.

Features
--------

* Guest browsing
* Student sign in and registration
* Committee and admin portal
* Society discovery and search
* Join and leave societies
* Announcements feed
* Event browsing and saving
* Society group chat
* Member approval for admins
* Admin tools for creating societies events and announcements
